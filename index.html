Why Sales Planning?

기획부터 구현, 결과 확인까지 한 흐름으로 프로젝트를 진행하였습니다. 원천 데이터와 화면 결과를 같은 기준으로 맞춰 보고, 사용자와 업무 담당자가 어디서 막히는지를 기준으로 문제를 정의하였습니다. 원인을 나눈 뒤에는 개선안을 실행하고, 개발·운영과 기준을 맞춰 가며 결과를 다시 확인하였습니다.

  • 데이터 분석 및 구조화 - CSV / Excel 전처리, 연도별 집계, API와 UI 대조처럼 비교 가능한 형태로 정리하였습니다.
  • 문제 정의 및 원인 분석 - 환경 차이, 권한, 집계 조건처럼 원인이 갈리는 지점을 나눠 보았습니다.
  • 업무 / 사용자 흐름 분석 - 역할별 접근 범위와 화면 흐름을 기준으로 문제를 구체화하였습니다.
  • 프로세스 개선 - 끊기는 흐름을 다시 잇고, 같은 조건으로 재확인하였습니다.
  • 협업 및 커뮤니케이션 - 실행 기준을 맞추고, 원인과 수정 내용을 문서화해 공유하였습니다.
  • 실행력 - 분석에서 그치지 않고 화면, 기능, 보고까지 직접 실행하였습니다.
  • 결과 확인 및 개선 - 정리한 기준과 실제 결과를 비교하고, 차이가 있으면 원인을 고쳤습니다.

이 경험을 바탕으로, 데이터를 기준으로 문제를 나누고 실행으로 연결하는 영업기획 업무를 배우고 성장하고자 합니다.
